英语口语练习助手


一个简单实用的英语口语练习桌面应用，支持文本朗读、翻译和生词本管理。
功能特性
🔊 语音朗读


支持朗读全部文本或选中文本
可调节语速（50-300）
使用系统自带的 TTS 引擎
🌐 翻译功能


英译中：选中英文文本一键翻译
中译英：支持中文翻译成英文
实时显示翻译结果
📚 生词本


双击英文单词自动添加到生词本
自动获取单词释义
支持手动添加生词和例句
生词搜索功能
导出生词到文本文件
SQLite 数据库存储
安装步骤
1. 环境要求


Python 3.8 或更高版本
Windows / macOS / Linux
2. 安装依赖


bash
# 进入项目目录
cd 英语口语练习App

# 安装依赖
pip install -r requirements.txt

3. 运行程序


bash
python main.py

使用指南
基本操作


导入文本
点击「打开文件」按钮导入 .txt 文件
或直接在文本框中粘贴/输入英文内容
语音朗读
点击「朗读全部」朗读整个文本
选中文本后点击「朗读选中」只朗读选中部分
拖动语速滑块调整朗读速度
翻译文本
选中英文文本，点击「翻译选中（英→中）」
选中中文文本，点击「翻译选中（中→英）」
翻译结果显示在下方翻译区
管理生词
在文本框中双击英文单词，自动弹出添加窗口
点击「手动添加」可以手动输入生词
在生词列表中双击单词可听取发音
使用搜索框快速查找生词
点击「导出」将生词本保存为文本文件

注意事项


语音引擎
Windows 系统默认使用 SAPI5 语音引擎
macOS 使用 NSSpeechSynthesizer
Linux 需要安装 espeak
翻译服务
使用免费的翻译 API，可能存在请求限制
如需更稳定的翻译服务，可考虑接入百度翻译、有道翻译等 API
字体问题
如界面显示乱码，请确保系统安装了中文字体
