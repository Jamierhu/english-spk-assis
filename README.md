# 英语口语练习助手


一个简单实用的英语口语练习桌面应用，支持文本朗读、翻译和生词本管理。<br>
## 功能特性
### 🔊 语音朗读
支持朗读全部文本或选中文本<br>
可调节语速（50-300）<br>
### 🌐 翻译功能
英译中：选中英文文本一键翻译<br>
中译英：支持中文翻译成英文<br>
实时显示翻译结果
### 📚 生词本
双击英文单词自动添加到生词本<br>
自动获取单词释义<br>
支持手动添加生词和例句<br>
### 生词搜索功能
### 导出生词到文本文件
### SQLite 数据库存储
## 安装步骤
### 1. 环境要求
Python 3.8 或更高版本
Windows / macOS / Linux
### 2. 安装依赖
```
pip install -r requirements.txt
```
### 3. 运行程序
```
bash
python main.py
```

本项目仅供学习和个人使用。
